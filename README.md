## 💼 Selected Case Studies & Production Builds

### 🏥 Case 01: [Distributed Patient Healthcare Microservices](https://github.com/ThomasShikalepo)
> **The Problem:** Healthcare monolithic applications suffer from bottlenecks where billing spikes or analytics workloads disrupt critical patient record access.  
> **The Architecture:** Engineered a decoupled microservices cluster (Patient, Billing, Analytics, API Gateway). Utilized **Apache Kafka** for event-driven message propagation, **gRPC** for low-latency inter-service calls, and containerized deployment with **Docker**.  
> **Tech:** `Java` • `Spring Boot` • `Apache Kafka` • `gRPC` • `Docker` • `PostgreSQL`

### 🌐 Case 02: [3D Interactive Developer Universe](https://thomasdeon.vercel.app/)
> **The Problem:** Traditional 2D developer portfolios fail to engage visitors or demonstrate advanced frontend and graphic capabilities.  
> **The Architecture:** Developed a production web application blending **Blender 3D** assets with client-side **Three.js** canvas rendering. Optimized 3D asset geometries and texture compression to achieve sub-second load times and fluid 60 FPS transitions.  
> **Tech:** `Next.js` • `Three.js` • `Tailwind CSS` • `Blender 3D`

### 🚚 Case 03: [Heuristic Route Optimization Engine](https://github.com/ThomasShikalepo)
> **The Problem:** Inefficient multi-stop delivery routes in newspaper logistics create fuel wastage, delayed drops, and high idle time.  
> **The Architecture:** Ingested real vehicle GPS telemetry, extracted delivery stops, built distance matrices, and solved the Traveling Salesperson Problem (TSP) using **Google OR-Tools** and Mapbox APIs.  
> **Tech:** `Python` • `Google OR-Tools` • `pandas` • `Mapbox API`

### 🎓 Case 04: [Work Integrated Learning Management Platform](https://github.com/ThomasShikalepo/Work_Integrated_System)
> **The Problem:** University internship placement programs struggle with fragmented supervisor communication, manual logbook evaluations, and unorganized student tracking.  
> **The Architecture:** Built an institutional portal supporting multi-role authentication (Students, Industry Mentors, Academic Supervisors). Features structured progress tracking, verification pipelines, and PDF certificate generation.  
> **Tech:** `Laravel` • `Inertia.js` • `React` • `PostgreSQL` • `Tailwind CSS`
